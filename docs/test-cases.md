# PathForge Quality Assurance: Manual Test Cases

This document outlines the structured manual QA test specifications for PathForge across all user flows, core domain modules, edge cases, responsive viewports, and stretch checkpoint features.

---

## Manual Test Cases Execution Matrix

| Test Case ID | Feature Area | Test Scenario & Steps | Expected Result | Status |
| :--- | :--- | :--- | :--- | :--- |
| **TC-AUTH-01** | Authentication | **User Registration (Happy Path)**<br>1. Navigate to `/signup`<br>2. Enter valid Name ("Jane Doe"), unique Email, matching password (`Password123!`)<br>3. Click "Sign Up" | Account created in MongoDB with bcrypt hash; JWT cookie set; user redirected to `/roles`. | **Pass** |
| **TC-AUTH-02** | Authentication | **Registration Password Mismatch**<br>1. Navigate to `/signup`<br>2. Enter Name, Email, Password (`Password123!`)<br>3. Enter mismatched Confirm Password (`Password456!`)<br>4. Click "Sign Up" | Inline validation error: "Passwords do not match"; form submission blocked; no network request. | **Pass** |
| **TC-AUTH-03** | Authentication | **Registration Weak Password Validation**<br>1. Navigate to `/signup`<br>2. Enter password shorter than 8 characters (e.g. `pass`)<br>3. Click "Sign Up" | Client-side error indicates password must be at least 8 characters with a letter and a number; submit disabled. | **Pass** |
| **TC-AUTH-04** | Authentication | **Registration Duplicate Email**<br>1. Register with an email already present in database<br>2. Submit form | Toast error notification: "A user with this email already exists" (HTTP 409 Conflict); user remains on signup page. | **Pass** |
| **TC-AUTH-05** | Authentication | **User Login (Happy Path)**<br>1. Navigate to `/login`<br>2. Enter registered credentials<br>3. Click "Sign In" | JWT token cookie set; user redirected to `/dashboard` if roadmap exists, or `/roles` if no role assigned. | **Pass** |
| **TC-AUTH-06** | Authentication | **User Login Invalid Password**<br>1. Navigate to `/login`<br>2. Enter valid email with incorrect password<br>3. Click "Sign In" | Generic alert: "Invalid email or password" (HTTP 401); no sensitive password details leaked. | **Pass** |
| **TC-AUTH-07** | Authentication | **User Logout & Session Clearance**<br>1. Log in to active account<br>2. Click "Sign Out" in header navbar<br>3.
