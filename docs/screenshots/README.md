## 🛠️ Capture Instructions

### Using Browser DevTools
1. Open Google Chrome or Chromium.
2. Press `F12` or `Ctrl+Shift+I` to open Developer Tools.
3. Toggle device emulation (`Ctrl+Shift+M`) and set dimensions to `1280 × 800` (or `360 × 780` for mobile).
4. Press `Ctrl+Shift+P`, type `Capture full size screenshot`, and press `Enter`.
5. Save files into `docs/screenshots/` using filenames matching `01-landing-hero.png`, `07-dashboard-overview.png`, etc.
